# Nand2Tetris 核心筆記：從組譯器到作業系統 (Ch 6 - Ch 12)

## 📋 第 6 章：組譯器 (Assembler)
**目標：** 將符號化組合語言 (.asm) 翻譯成二進制機器碼 (.hack)。

### 1. 核心流程
組譯器填補了人類可讀代碼與硬體電路之間的溝通鴻溝。
* **輸入：** `Prog.asm` (文字檔)
* **輸出：** `Prog.hack` (16-bit 二進制字串)

### 2. 指令翻譯邏輯
* **A-指令 (@value)：**
    * 若為數字：將值轉為 15 位元二進制，最高位補 `0`。
    * 若為符號：查詢符號表獲取對應地址。
* **C-指令 (dest=comp;jump)：**
    * 格式：`111 a cccccc ddd jjj`
    * `comp` (acccccc)：計算邏輯。
    * `dest` (ddd)：結果儲存位置 (M, D, A)。
    * `jump` (jjj)：跳轉條件 (JGT, JEQ 等)。

### 3. 符號處理與兩次掃描 (Two-Pass)
1. **第一次掃描：** 建立標籤符號表。尋找 `(LABEL)`，記錄其下一行指令的 ROM 地址。
2. **第二次掃描：** 翻譯指令。處理變數符號（如 `@sum`），若為新變數，從 RAM 16 開始依序分配地址。

## ⚙️ 第 7-8 章：虛擬機 (Virtual Machine)
**目標：** 實作 VM Translator，將基於堆疊 (Stack) 的指令轉為 Hack 組合語言。

### 1. 堆疊機模型 (Stack Machine)
所有運算均在堆疊頂端進行。
* **二元運算：** Pop `y`, Pop `x` -> 計算 `x op y` -> Push 結果。
* **邏輯運算：** 結果 True 存 `-1` (全 1)，False 存 `0`。



### 2. 記憶體區段映射 (Memory Mapping)
| 區段 (Segment) | 實體實作方式 |
| :--- | :--- |
| `local, argument, this, that` | 基於 `LCL, ARG, THIS, THAT` 指標加上偏移量 (Index) |
| `temp` | 固定映射至 RAM 5 - 12 |
| `pointer` | 0 -> `THIS` (RAM 3), 1 -> `THAT` (RAM 4) |
| `static` | 翻譯為組譯器標籤 `FileName.i` |
| `constant` | 虛擬區段，直接 `push` 數值 |

### 3. 函式呼叫協定 (Calling Protocol)
* **Call：** 保存當前狀態（返回地址、LCL, ARG...），重設 ARG 與 LCL 地址。
* **Function：** 建立入口標籤，初始化區域變數空間 (Push 0)。
* **Return：** 恢復 Caller 的指標，將結果移至 `*ARG` 位置，回收堆疊空間。

## 💻 第 9-11 章：Jack 語言與編譯器 (Compiler)
**目標：** 將高階 OOP 語言 Jack 編譯為 VM 代碼。

### 1. 詞彙與語法分析 (第 10 章)
* **Tokenizer：** 將代碼切割為五類標記 (Keyword, Symbol, Identifier, Int, String)。
* **Parser：** 採用 **遞迴下降法 (Recursive Descent)** 構建解析樹。

### 2. 代碼生成 (第 11 章)
* **符號表 (Symbol Table)：** * 分為 **Class 級別** (static/field) 與 **Subroutine 級別** (arg/var)。
    * 記錄變數的 Name, Type, Kind, Index。
* **物件與陣列：**
    * **Constructor：** 呼叫 `Memory.alloc` 分配大小，設定 `THIS` 指標。
    * **Method：** `argument 0` 永遠是當前物件的參照 (this)。
    * **Array：** 利用 `pointer 1` (THAT) 進行地址偏移運算。

## 🛠️ 第 12 章：作業系統 (Operating System)
**目標：** 實作 8 個支援軟體執行的核心類別。

### 1. 核心類別精華
* **Math：** 實作 `multiply` (Shift-and-Add) 與 `divide` (遞迴長除法)。
* **Memory：** 實作 `alloc` 與 `deAlloc`。使用 **Free List** 演算法管理 Heap。
* **Screen：** 實作像素繪製，並使用 **Bresenham 演算法** 高效繪製線條。
* **Output：** 管理字型圖案 (Font Map) 並將其 `poke` 到 Screen 記憶體。
* **String：** 處理字元與數字轉換（ASCII 偏移量應用）。
* **Sys：** 系統引導程序，初始化所有類別並呼叫 `Main.main`。

### 2. 重要提醒
* **指標操作：** 在 Jack 中使用 `Array ram; let ram = 0;` 來實作 `peek` 與 `poke`。
* **效率問題：** 由於硬體無乘法器，所有圖形運算必須極度優化以減少運算開銷。
